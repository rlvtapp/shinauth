## Prerequisites

    Before you begin, make sure you have:

    1. A working [Shinauth](/installation) installation
    2. An account & API Key from the [Shinauth Infrastructure](/dashboard) dashboard



    ## Installation

    Install the `@shinauth/infra` package:

    ```bash
    @shinauth/infra
    ```



    ## Environment Variables

    Once you've gotten the API Key from the infrastructure dashboard,
    go ahead and add the `BETTER_AUTH_API_KEY` environment variable in your production environment variables.

    ```dotenv
    # Required: Your Shinauth Infrastructure API key
    BETTER_AUTH_API_KEY=your_api_key_here
    ```


**Note:**

      You can get your API key by signing-up and creating a new project in the
      [Shinauth Infrastructure dashboard](/dashboard).




## Server Setup

### Basic Configuration

Add the `dash()` plugin to your Shinauth configuration:

```ts
import { shinAuth } from "shinauth";
import { dash } from "@shinauth/infra";

export const auth = shinAuth({
  // ... your existing Shinauth config
  plugins: [
    dash({
      apiKey: process.env.BETTER_AUTH_API_KEY,
    }),
  ],
});
```

If you're on **pro** plan or above, you can use the `sentinel()` plugin to enable security checks, abuse protection, and more:

```ts
import { shinAuth } from "shinauth";
import { dash, sentinel } from "@shinauth/infra";

export const auth = shinAuth({
  plugins: [
    dash({ /* ... */ }),
    sentinel({
      apiKey: process.env.BETTER_AUTH_API_KEY,
    })
  ],
});
```

## Client Setup

### Basic Client Configuration

Add the client plugins to your auth client:

```ts
import { createAuthClient } from "shinauth/client";
import { dashClient, sentinelClient } from "@shinauth/infra/client";

export const authClient = createAuthClient({
  plugins: [
    dashClient(),
    sentinelClient({
      autoSolveChallenge: true, // Automatically solve PoW challenges
    }),
  ],
});
```

### Expo and React Native

For **Expo** or **React Native** clients, import from `@shinauth/infra/native` instead of `@shinauth/infra/client`. The native entry provides `dashClient` (same audit log APIs as the web client) and `sentinelNativeClient`.

```ts
import { createAuthClient } from "shinauth/client";
import { dashClient, sentinelNativeClient } from "@shinauth/infra/native";

export const authClient = createAuthClient({
  baseURL: "https://your-api.example.com",
  plugins: [
    dashClient(),
    sentinelNativeClient({
      autoSolveChallenge: true,
    }),
  ],
});
```

See [Sentinel — Expo and React Native](/infrastructure/plugins/sentinel#expo-and-react-native) for more details.

### Plugin Overview

* **`dash()`** - Enables analytics tracking, audit logging, dashboard admin APIs, and more
* **`sentinel()`** - Enables security checks and abuse protection

You can use either plugin independently, but using both together provides the full Shinauth Infrastructure experience.
