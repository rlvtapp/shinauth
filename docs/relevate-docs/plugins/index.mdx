Shinauth ships with 50+ plugins that extend the framework with additional auth features, payment integrations, security tools, and more.

## Authentication

| Plugin                                          | Description                                                |
| ----------------------------------------------- | ---------------------------------------------------------- |

| [Magic Link](/plugins/magic-link)               | Passwordless email magic link authentication               |
| [Email OTP](/plugins/email-otp)                 | Email-based one-time password authentication               |
| [Phone Number](/plugins/phone-number)           | Phone number authentication                                |
| [Anonymous](/plugins/anonymous)                 | Anonymous/guest session support                            |
| [Username](/plugins/username)                   | Username-based authentication                              |
| [One Tap](/plugins/one-tap)                     | Google One Tap sign-in                                     |
| [Sign In With Ethereum](/plugins/siwe)          | Ethereum wallet authentication                             |
| [Generic OAuth](/plugins/generic-oauth)         | Authenticate users with any OAuth provider                 |
| [Multi Session](/plugins/multi-session)         | Multiple concurrent sessions per user                      |
| [Last Login Method](/plugins/last-login-method) | Track the last authentication method used                  |
