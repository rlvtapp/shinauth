# Shinauth Electron Example

This is an example of how to use Shinauth with Electron.

## Prerequirements

Make sure you've set-up the [Shinauth Demo App](../nextjs/README.md).

## How to run

1. Clone the repo and open it in your code editor
2. Run the following commands

  ```bash
  pnpm install
  pnpm dev
  ```

Checkout the [electron guide](https://www.shinauth.com/docs/integrations/electron) to learn more.
