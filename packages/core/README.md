# Shinauth Core

Core utilities and types for [Shinauth](https://github.com/rlvtapp/shinauth) — the most comprehensive authentication framework for TypeScript.

## Installation

```bash
npm install @shinauth/core
```

## Documentation

For full documentation, visit [github.com/rlvtapp/shinauth](https://github.com/rlvtapp/shinauth).
