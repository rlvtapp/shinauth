# Shinauth CIMD Plugin

Client ID Metadata Document plugin for [Shinauth](https://www.shinauth.com): unauthenticated dynamic client discovery over HTTPS, the mechanism [MCP](https://modelcontextprotocol.io/specification/draft/basic/authorization#client-id-metadata-documents-flow) uses for authorization servers to discover clients without prior registration.

## Installation

```bash
npm install @shinauth/cimd
```

## Documentation

For full documentation, visit [shinauth.com/docs/plugins/cimd](https://www.shinauth.com/docs/plugins/cimd).
