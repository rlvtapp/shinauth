# Shinauth Redis Storage

Redis storage for [Shinauth](https://github.com/rlvtapp/shinauth) secondary storage — use Redis for session caching and rate limiting.

## Installation

```bash
npm install @shinauth/redis-storage
```

## Documentation

For full documentation, visit [github.com/rlvtapp/shinauth](https://github.com/rlvtapp/shinauth).
