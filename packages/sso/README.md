# Shinauth SSO Plugin

Single Sign-On plugin for [Shinauth](https://github.com/rlvtapp/shinauth) — add SAML and OIDC enterprise SSO to your application.

## Installation

```bash
npm install @shinauth/sso
```

## Documentation

For full documentation, visit [github.com/rlvtapp/shinauth](https://github.com/rlvtapp/shinauth).
