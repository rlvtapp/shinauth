# Shinauth SSO Plugin

Single Sign-On plugin for [Shinauth](https://www.better-auth.com) — add SAML and OIDC enterprise SSO to your application.

## Installation

```bash
npm install @shinauth/sso
```

## Documentation

For full documentation, visit [better-auth.com/docs/plugins/sso](https://www.better-auth.com/docs/plugins/sso).
